הכנס Script URL אחד — כולם מסונכרנים אוטומטית, ללא צורך בהגדרות נוספות.
כיצד יוצרים Script URL? (פעם אחת, 5 דקות)
  1. כנס ל-script.google.com ← לחץ + New project
  2. מחק את הקוד הקיים והדבק את קוד ה-GAS (מופיע למטה)
  3. לחץ Deploy → New deployment
    Type: Web app | Execute as: Me | Who has access: Anyone
    לחץ Deploy ← אשר הרשאות ← העתק את ה-URL
  4. הדבק את ה-URL בשדה "Script URL" למעלה ולחץ שמור
  5. שלח את אותו URL לכל המשתמשים — כולם יכניסו אותו ויסונכרנו אוטומטית

סנכרון ישיר ל-Drive (חשבון יחיד) — Client ID
ה-Client ID נשמר במכשיר זה בלבד.

כדי לסנכרן עם משתמשים שיש להם חשבון Gmail שונה — הזן כאן את ה-File ID של קובץ Drive משותף.

📄 File ID של הקובץ שלך — העתק ושתף:
איך מקבלים Client ID? (5 דקות, פעם אחת)
  1. כנס ל-console.cloud.google.com ← צור פרויקט חדש
  2. APIs & Services → Library ← חפש Google Drive API ← Enable
  3. Credentials → + Create → OAuth 2.0 Client ID
  4. Application type: Web application
    Authorized JavaScript origins — הוסף את כתובת ה-GitHub Pages שלך
  5. לחץ Create ← העתק את ה-Client ID ← הדבק בשדה למעלה
